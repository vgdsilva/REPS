# TrainingApp
TrainingApp is an open-source, offline-first workout tracker built with C# and .NET.

## Inspiration

TrainingApp was inspired by the open-source project [openGym](https://github.com/arvids-unavailable/openGym).

TrainingApp is an independent implementation built from scratch in C#/.NET, with its own architecture and codebase.

The project takes inspiration from some of openGym's ideas and user experience, but does not reuse its source code.
